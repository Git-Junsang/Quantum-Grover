- **문제**: 논문 Algorithm 2(DHA)에는 m 갱신 줄이 아예 없다. PDF p.5(22607) Algorithm 2를 직접 렌더링해 확인한 결과, else 분기는 line 13 "Go back to Step 3;"가 전부다. m ← min(λm, √K)는 Algorithm 1(BBHT) line 11에만 존재한다. 또 Algorithm 2에는 추출이 누락한 line 8-9 (L_BBHT = L_BBHT + j; L_DHA = L_DHA + L_BBHT)라는 특이한 이중 누적이 있다. 다만 본문 p.12에는 "DHA starts with a random value taken in an interval L ∈ {0,...,⌊m⌋} ... with m gradually increasing from 1"이라고 적혀 있어, 저자의 의도는 m 증가가 맞지만 의사코드가 이를 반영하지 못한 논문 자체의 결함이다.

### 정정 2

- **문제**: LaTeX 자체는 논문 (8)식과 정확히 일치하지만, 해설이 수식과 모순된다. 논문 (8)식은 정규화 상수가 1/√K이고 K = 2^N이다. 이 논문에서 N은 '사용자 수'이지 데이터베이스 크기가 아니므로 1/√N은 틀린 값이다. N=11이면 정답은 1/√2048 ≈ 0.0221인데 1/√11 ≈ 0.3015가 되어 40배 이상 어긋난다.

### 정정 3

- **틀린 주장**: equations의 Lopt 항목 meaning "S = 1이면 익숙한 (π/4)√N" 및 glossary의 Lopt 항목 "S = 1이면 익숙한 (π/4)√N"

- **문제**: 논문 표기에서 N은 사용자 수, K = 2^N이 데이터베이스 크기다. Lopt = ⌊(π/4)√(K/S)⌋에 S = 1을 넣으면 (π/4)√K = (π/4)√(2^N)이지 (π/4)√N이 아니다. 교과서에서 흔히 쓰는 'N = 데이터베이스 크기' 표기를 이 논문의 'N = 사용자 수'와 뒤섞은 결과로, 같은 문서 안에서 N이 두 가지 의미로 쓰이게 되어 학습 자료로서 특히 위험하다.

- **바른 서술**: "S = 1이면 (π/4)√K = (π/4)√(2^N). (교과서의 '(π/4)√N'은 N이 데이터베이스 크기일 때의 표기이며, 이 논문의 N은 사용자 수이므로 혼동 주의)"로 수정.

**누락된 중요 내용:**

1. **Fig. 8의 반전 현상 (가장 중요한 누락)**: 논문 p.12에 "In Fig. 8(d)–(f), it can be seen that **DHA with the additional classical algorithm (ZF and CCR) outperforms IIMSA, especially when L is small**"이라고 명시되어 있습니다. 즉 L이 작은 영역에서는 n_bit 기준으로 ZF-DHA/CCR-DHA가 IIMSA를 이깁니다(IIMSA는 Lopt 때문에 처음부터 큰 반복 수로 시작하는 반면 DHA는 m=1부터 시작하므로 while 조건을 더 작은 값에서 넘김). 추출의 results는 "IIMSA가 모든 SF·모든 σ²·모든 코드군에서 DHA보다 적음"(Fig.5 한정으로는 맞음)만 담고 있어, "IIMSA가 항상 우월"이라는 인상을 줍니다. FSM 설계 관점에서 "L_max를 작게 잡으면 IIMSA가 손해"라는 건 우리 프로젝트에 직접 영향을 주는 조건이므로 반드시 추가해야 합니다.

2. **논문의 Reference 레지스터 자기모순**: p.6에서 "Reference register δ"(임계값을 담음)라고 해놓고, 같은 페이지 뒤에서 "the reference register in Grover's algorithm is fed with y_q as shown in Fig. 3"(수신신호를 담음)이라고 씁니다. 또 4개 레지스터 목록(Index/Reference/Ancilla/Mark)에는 없는 **"value register"**가 "the qubits number for the value and reference registers are Z qubits"에 갑자기 등장합니다. 추출은 "Reference = δ"만 채택했는데(Fig.3의 |a⟩=|δ⟩와 일치하므로 타당한 선택), 이 모순을 limitations에 적어두는 게 좋습니다 — 구현할 때 y와 δ 중 무엇을 어느 레지스터에 넣을지 우리가 직접 정해야 한다는 뜻이기 때문입니다.

3. **(14)식과 Unipolar 구체 예시 누락**: 논문 p.7에 N=4, SF=3, c1=[1,1,0], c2=[0,1,1], c3=[0,0,1], c4=[1,0,1]이고 무잡음 기대신호가 f(b1,b2,b3,b4) = [b1+b4, b1+b2, b2+b3+b4]ᵀ라는 (14)식이 있습니다. equations 목록에 빠져 있는데, **이게 b·C 계산이 실제로 어떤 하드웨어가 되는지 보여주는 유일한 구체 예시**입니다. 곱셈기 없이 "b 비트가 1인 행만 조건부 누산"이라는 project_relevance의 주장을 논문으로 직접 뒷받침하는 근거이므로 넣을 가치가 큽니다.

4. **(13)식의 인쇄 모호성**: PDF 원문에는 ", 2I−1"로 조판되어 있어 2^I − 1인지 2^(I−1)인지 식만 봐서는 구분되지 않습니다. 다만 본문 "The retained integer part of y is upper bounded by 2^I − 1"이 있으므로 추출의 해석(2^I − 1)이 맞습니다. 구현 시 참고하도록 각주로 남길 만합니다.

5. **N ≥ SF 제약**: 논문 p.2 "we assume that N ≥ SF users belong to the network"라는 시스템 전제가 빠져 있습니다. Table I가 왜 그런 SF→N 조합인지 설명해주는 조건입니다.

6. **선행연구 Botsinis [9]의 상한 표기 차이**: 논문 p.2는 Botsinis의 반복 상한을 22.5√(K/S)로 인용하는데, 정작 이 논문 자신의 DHA 상한(Section IV-A, Algorithm 2)은 22.5√K입니다. 같은 상수 22.5인데 S가 있고 없고가 다릅니다. 추출은 22.5√K만 담았고 그건 맞지만, 논문 내 표기 불일치로 limitations의 "(12)식 부호 규약 오류" 목록에 함께 적어두면 좋겠습니다.

7. **Fig. 5의 Gaussian 복잡도 서술**: p.8에 "Gaussian is the one where the complexity is the smallest thanks to its small Euclidean distance"라고 되어 있는데, Fig. 8(p.12)에서는 Gaussian n_bit가 25로 Bipolar 18보다 큽니다. 실험 조건이 달라 직접 모순은 아니지만, 추출의 "Gaussian이 가장 약함" 서술과 함께 두면 혼동될 수 있어 조건(Fig.5는 σ² 스윕, Fig.8은 L 스윕·σ=0.1·SF=6)을 병기하는 게 안전합니다.

**project_relevance / beginner_hooks 평가**: 대부분 논문 사실이 아니라 우리 프로젝트로의 해석·확장 제안이며, "이 자원 계산은 우리 추정이며 논문에는 없다", "논문의 I, p는 진폭 α의 폭이 아니다" 같이 **논문 근거와 자체 추론을 명시적으로 구분해 표시한 점은 정확하고 정직합니다**. limitations의 "FPGA 구현이 아니다 — LUT/FF/DSP/BRAM/주파수 수치가 하나도 없다"도 원문 대조 결과 사실입니다(논문 전체에 하드웨어 자원 수치 전무). 다만 위 corrections 2·3의 1/√N·(π/4)√N 오류는 beginner_hooks와 glossary에 반복 등장하므로, 초보자용 해설서에 그대로 실리면 N의 의미 혼동을 일으킵니다 — 일괄 수정 권장합니다.
