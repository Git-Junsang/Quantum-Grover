# 발표자료

이 프로젝트에서 실제로 발표한 자료를 모아 둡니다. **발표 시점의 기록이므로 내용을 사후 수정하지 않는 것이 원칙**입니다. 그래서 지금 확정된 설계와 어긋나는 대목이 있고, 아래 표의 "현행 대비" 열이 그 차이를 밝힙니다.

## 이름 규칙

```
YYYY-MM-DD_<종류>_<주제>.<확장자>
```

- `YYYY-MM-DD` — **발표한 날짜**(파일을 만든 날이 아니라). 앞에 두면 목록이 그대로 시간순이 됩니다.
- `<종류>` — `세미나`(학습·공유용) / `아키텍처`(설계 결정 보고용)
- `<주제>` — 하이픈으로 이은 짧은 구. 공백을 쓰지 않아 셸에서 따옴표 없이 다룰 수 있습니다.

같은 발표의 `.pptx` 와 `.pdf` 는 확장자만 다르게 하여 짝을 이룹니다.

## 2026-07-29 아키텍처 덱에서 바뀐 결정

이 덱은 프로젝트의 스펙 결정표(S0-1 ~ S4-5)를 처음 정리한 자료이고 대부분의 결정이 지금도 유효합니다. 다만 다음 여섯 가지는 그 뒤 뒤집혔습니다. **이 덱을 인용할 때는 반드시 확인하십시오.**

| 덱의 결정 | 현행 | 왜 바뀌었나 |
|---|---|---|
| 목표 FPGA **XC7S100**, n=16 | **Arty-S7-50** (`xc7s50csga324-1`), n=15 | RVX에 `xc7s100` imp class가 없고, 실제 보유 예정 보드가 Arty-S7-50 |
| S1-3 **Q1.17** | **Q2.16** (DW=18 유지) | 확산 중간값 `2·mean − amp` 의 상한이 `1 + 2/√N` 이라 1을 넘음 — Q1.17에는 여유가 없음 |
| S3-5 측정 = **직렬 CDF, DSP 1개** | **2단 병렬**(뱅크별 CDF → 뱅크 내 스캔), DSP 32개 | BBHT는 평균 24.5샷(n=15·M=1·몬테카를로 20,000회)이라 직렬 측정이 전체 시간의 절반을 먹음 |
| S3-1 **MicroBlaze + AXI** | **RVX**(`rvc_orca`) + APB 슬레이브 · AHB 마스터 | SoC를 RVX로 생성하기로 하면서 코어가 `rvc_orca` 로 바뀜. 제어는 APB로 충분하고 데이터 적재는 버스트가 필요해 AHB. RVX에 `axi`·`axi4`·`axi4l` 심은 있지만 **AXI-Stream 심은 없어** 초기의 `data_loader` 원안만 따로 폐기 |
| 재시도 = **진폭 배열 전체 재기입** | **재개 캐시** — 차이만큼만 이어 전진 | 측정이 읽기 전용이라 실패한 샷 뒤에도 상태가 남음 |
| 측정 비용 "샷당 약 7%" | BBHT 샷 수열 기준으로는 **절반 가까이** | 7%는 M을 아는 단일 샷 기준 수치였음 |

현행 확정 스펙의 단일 출처는 [해설서 15.4절](../study_references/15_논문지도와_설계결정표.md#154-우리-프로젝트의-좌표--확정-설계-결정표)입니다.
