# BBHT/Grover 다중 타겟 탐색 가속기 기술문서

> 중앙대학교 학부인턴 · LPSoC BBHT/Grover 프로젝트
> RVX SoC 커스텀 IP + 호스트 UART 제어 (Arty A7-100T / Artix-7 `xc7a100tcsg324-1`)

---

## 0. 이 문서에 대하여

이 기술문서는 알고리즘, 소프트웨어 기준모델, RTL, 인터페이스 계약, 검증, 보드 운용, Vivado
구현, 그리고 설계를 정한 근거 실험까지 한 벌로 설명합니다. 팀 안의 인수인계와 설계 검토가 주된
목적이고, 처음 코드를 접하는 개발자도 이 문서만으로 시스템의 동작과 구현을 따라갈 수 있도록
썼습니다. 양자컴퓨팅 기초부터 필요하면 학습용 해설서
[`study_references/`](../study_references/00_양자컴퓨팅_시작하기.md)의 0장부터 읽는 편이 좋고,
알고리즘을 이미 안다면 [3장](03_Grover와_BBHT_알고리즘.md)부터 읽어도 됩니다.

### 0.1 대상 독자

- 프로젝트에 새로 합류해 전체 구조를 빠르게 파악해야 하는 팀원
- RTL 모듈을 고치기 전에 그 모듈의 동작 · 포트 · 계약을 확인하려는 개발자
- 궤적이나 사이클이 어긋났을 때 데이터 형식 · 메모리 맵 · 검증 체계를 거슬러 올라가야 하는 사람
- 보드에 굽고 호스트에서 직접 명령을 넣어 보려는 사람

### 0.2 현재 문서 범위

기준 시점은 2026-10-04 입니다.

| 영역 | 상태 | 수록 |
|---|---|---|
| BRAM 갈래 최종 구성 (`hardware_bram/` 의 `K3H3_E4_M2` 모델) RTL · 검증 | 보드 실측 완료 (2026-09-08 정본 빌드) | 1~20장 |
| 통신 계층 교체판 | 2026-09-17 보드에서 명령 왕복 확인 | 7장 · 18장 |
| 성능 세 축 (보드 시간 · RTL 사이클 · ORCA 대비) | 2026-09-08 정본 빌드 기준 | 1장 · 15장 |
| 네 술어 × 500 워크로드 (Predicate500) | 세 판 RTL · SoC RTL 시뮬 · 보드(2026-10-04, 8,000 실행)까지 기준모델과 일치 | 16장 · 18장 · 19장 |
| 체크포인트 없는 비교 기준 판 (`nocheckpoint` 모델) | 보드 실행 2,000/2,000 (2026-10-04). 같은 보드에서 체크포인트 판이 실경과 2.810배 빠름 | 21장 |
| DRAM 갈래 (`hardware_dram/`) | 보드 실행 2,000/2,000 (2026-10-04, DDR3 실물). 열거 · 프리페치 없음 | 22장 |
| 설계 결정의 근거 실험 | 2026-08 골든 모델 캠페인 ~ 2026-09-09 K/H 분리 실험 | 23장 |

## 3. 문서 표기 규약

- 신호 · 포트 · 모듈명: 코드 식별자는 `cfg_predicate_mode`, `grover_bbht_shot_fsm`, `S_PASS1` 처럼
  씁니다.
- 소스 인용: 가능하면 [`bbht_grover_main_ip.v`](../../hardware_bram/src/bbht_grover_main_ip.v)
  처럼 실제 파일을 상대 링크로 겁니다. 라인 번호는 코드 변경에 따라 달라지므로 모듈명이나 신호명을
  기준으로 찾습니다.
- 수식: 본문에 LaTeX 를 쓰지 않고 코드 블록이나 산문으로 풉니다.
- 다이어그램: 본문에 mermaid fence 를 직접 쓰지 않고 `<img>` 로 SVG · PNG 를 참조합니다. 그림은
  [`diagrams/`](diagrams/) 하나에 두고, mermaid 소스는 `diagrams/src/*.mmd` 에서
  [`render_diagrams.py`](render_diagrams.py) 로 렌더합니다.
- 성능 수치: 보드 실경과 시간, RTL 사이클, 소프트웨어 대비 중 어느 축인지 함께 적고, 다른 축을
  섞어 배수를 만들지 않습니다([1장 1.5절](01_프로젝트_개요.md#15-성능-지표와-인용-기준)).
- 한 수치는 한 장에만 적습니다. 다른 장은 그 절로 링크합니다.
- 미확인: 검증하지 않은 항목은 해당 장에서 범위와 함께 밝힙니다.
- 13장은 `software/contract/gen_csr.py` 가 CSR 정본 JSON 에서 생성합니다. 손으로 고치지 않습니다.
