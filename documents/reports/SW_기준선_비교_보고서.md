# SW 기준선 대 FPGA 가속기 — 측정 결과 보고

2026-10-11 측정 · 비교 대상 FPGA 측정 2026-10-08 · 상세는 [기술문서 25장](../design_references/25_SW_기준선과_FPGA_비교.md)

## 요약

- 같은 Grover/BBHT 탐색을 세 곳에서 돌렸습니다. 200T 보드의 ORCA 코어(50 MHz), 서버의 x86 코어 하나,
  같은 보드의 FPGA 가속기 K3/H3-E4-M2(100 MHz)입니다. 워크로드는 네 술어 × M 5종 × seed 100 = 2,000개로 같습니다.
- **세 곳의 결과가 2,000/2,000 같습니다.** 결과 인덱스 · 시도 수 · L · 실제 반복이 모두 같습니다.
- **FPGA 는 ORCA 보다 실경과 시간으로 약 1.6만~2만 배 빠릅니다.**
- **서버 x86 코어 하나는 FPGA 와 시간이 비슷합니다.** 전체로 1.15~1.34배 더 걸리고, M = 64 · 256 에서는 FPGA 보다 빠릅니다.

## 비교한 것

| 모델 | 내용 | 맞대는 FPGA 모드 |
|---|---|---|
| ③ 최적화 Normal | 반복 1회에 배열을 한 번 훑는 C | normal |
| ② 최적화 + K3H3 | ③ 에 FPGA 와 같은 체크포인트 정책을 더한 C | ckpt |
| ① naive | 행렬 × 벡터를 그대로 곱하는 C (최적화 효과를 보는 보조 기준) | normal |

C 소스는 세 곳에서 같습니다. 시간 구간은 탐색 시작부터 결과까지이고, 데이터 준비는 뺐습니다.

## 결과 — 시간과 사이클

2,000개 합입니다.

| 실행 환경 | 모델 | 시간 | 사이클 |
|---|---|--:|--:|
| ORCA 보드 (50 MHz) | ③ Normal | 9,512.4초 (2시간 38분) | 4,756억 |
| ORCA 보드 | ② K3H3 | 3,511.8초 (58.5분) | 1,756억 |
| ORCA 보드 | ① naive | 약 4.58년 (추정) | — |
| 서버 x86 코어 하나 (약 5.3 GHz) | ③ Normal | 0.552초 | 29.1억 |
| 서버 | ② K3H3 | 0.297초 | 15.7억 |
| 서버 | ① naive | 12,802초 (3시간 33분) | 67.3조 |
| FPGA K3/H3-E4-M2 (100 MHz) | normal | 0.479초 | 4,689만 |
| FPGA | ckpt | 0.221초 | 2,108만 |

ORCA 사이클은 시간 × 50 MHz 로 환산한 값입니다. 서버는 코어 사이클 카운터 실측값, FPGA 는 가속기 사이클
카운터 값입니다. ORCA ① 은 반복 1회에 19.2분이라 끝까지 돌리지 않고 단가로 추정했습니다. 두 워크로드를 끝까지
돌려 추정식과 0.003% 차이임을 확인했습니다.

## 결과 — FPGA 대비 배수 (시간)

같은 모드끼리 맞댄 값입니다. 1보다 크면 FPGA 가 빠릅니다.

| 비교 | 전체 | M=1 | M=4 | M=16 | M=64 | M=256 |
|---|--:|--:|--:|--:|--:|--:|
| ORCA ③ ÷ FPGA normal | 19,861 | 21,708 | 20,080 | 18,089 | 15,494 | 12,227 |
| ORCA ② ÷ FPGA ckpt | 15,889 | 19,330 | 16,357 | 13,304 | 10,434 | 8,103 |
| 서버 ③ ÷ FPGA normal | 1.15 | 1.25 | 1.16 | 1.06 | 0.93 | 0.77 |
| 서버 ② ÷ FPGA ckpt | 1.34 | 1.53 | 1.41 | 1.22 | 0.99 | 0.79 |

사이클로 보면 FPGA 는 같은 일을 ORCA 보다 8,328~10,144배, 서버보다 62~74배 적은 클럭으로 끝냅니다.

## 결과 — 체크포인트 효과

실제 반복은 세 곳 모두 125,106 → 37,659 로 같이 줄었습니다(3.32배).

| | ORCA 보드 | 서버 | FPGA |
|---|--:|--:|--:|
| 시간 단축 (Normal ÷ 체크포인트) | 2.71배 | 1.86배 | 2.17배 |

## 읽을 때 주의

- ORCA 대비 만 단위 배수는 알고리즘 우위가 아니라, 코어 하나 대 P = 32 레인 병렬과 클럭 2배의 차이입니다.
- 서버 한 코어가 FPGA 와 비슷하다는 결과를 가속 효과와 같이 밝혀야 합니다. 서버는 클럭이 약 53배 높고
  SIMD 자동 벡터화가 들어간 빌드입니다.
- 이 비교는 200T 보드 · 네 술어 2,000개 · 새 기준선 코드입니다. 성능 세 축의 정본(100T 보드, EQ 500,
  ORCA 대비 116,426x)과 섞지 않습니다.
