# 2026-10-05 C++ · NumPy · Qiskit 서버 측정

[`run_all.sh`](../../pc_grover_develop/campaign/run_all.sh) 를 서버(`Intern-Ubuntu`, Intel Core
i5-14600K, 컨테이너라 E 코어 8개만 사용, 1코어 실행은 CPU 13 고정)에서 한 번 돌린 결과입니다. 수치와 해석은
[실험 17](../../../documents/reports/17_CPP_NumPy_Qiskit_기준선.md)에 있고, 이 문서는 폴더 안내만 합니다.

| 위치 | 내용 |
|---|---|
| `environment.txt` | CPU · 쓸 수 있는 코어 · 고정 CPU 와 최대 클럭 · 가상화 · 컴파일러 · 파이썬 패키지 판본 |
| `run.log` | 캠페인 콘솔 출력 |
| `verification/` | 데이터셋 해시, C++ ↔ RTL 벡터, 오라클, C++ ↔ 기준모델 ↔ 보드 대조 (전부 PASS) |
| `predicate500/report/report.md` | 주 실험 보고서: 시간 · 처리량 · 동치성 · 분포 검정 |
| `predicate500/report/summary_by_backend.csv` · `all_backends.csv` | 그래프 · 표용 원자료 |
| `predicate500/runs/` · `common500/` | 백엔드 · 구성별 원시 CSV 와 요약 JSON, Common500 같은 구성 |
| `energy/` | 비어 있음 (`ENERGY=1` 로 돌리지 않음) |

`verification/predicate500_datasets_regenerated/` 는 다시 만들 수 있는 사본이라 저장소에 올리지 않았습니다.
`run.log` 의 경로는 측정 당시 위치(`software/sw_benchmark/results/...`)이고 고치지 않습니다.
