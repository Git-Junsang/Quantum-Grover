# 2026-10-05 C++ · NumPy · Qiskit server benchmark

[`run_all.sh`](../../pc_grover_develop/campaign/run_all.sh) 를 server(`Intern-Ubuntu`, Intel Core
i5-14600K, container라 8 E-cores만 사용, 1 core 실행은 CPU 13 고정)에서 한 번 돌린 결과입니다. 수치와 해석은
[실험 17](../../../documents/reports/17_cpp_numpy_qiskit_baselines.md)에 있고, 이 문서는 directory 안내만 합니다.

| 위치 | 내용 |
|---|---|
| `environment.txt` | CPU · 쓸 수 있는 core · 고정 CPU와 최대 clock · 가상화 · compiler · Python package version |
| `run.log` | campaign console 출력 |
| `verification/` | dataset hash, C++ ↔ RTL test vector, oracle, C++ ↔ reference model ↔ board 대조 (전부 PASS) |
| `predicate500/report/report.md` | 주 실험 보고서: 시간 · throughput · 동치성 · 분포 검정 |
| `predicate500/report/summary_by_backend.csv` · `all_backends.csv` | graph · 표용 원자료 |
| `predicate500/runs/` · `common500/` | backend · 구성별 원시 CSV와 요약 JSON, Common500 같은 구성 |
| `energy/` | 비어 있음 (`ENERGY=1` 로 돌리지 않음) |

`verification/predicate500_datasets_regenerated/` 는 다시 만들 수 있는 사본이라 저장소에 올리지 않았습니다.
`run.log` 의 경로는 benchmark 당시 위치(`software/sw_benchmark/results/...`)이고 고치지 않습니다.
