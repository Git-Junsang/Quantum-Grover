# 2026-10-05 C++ · NumPy · Qiskit 개발 VM 예비 benchmark

같은 [`run_all.sh`](../../pc_grover_develop/campaign/run_all.sh)를 개발 VM(cloud Xeon 2.8 GHz,
2 vCPU, `REPS=1 QISKIT_SEEDS=2`)에서 돌린 흐름 확인용 결과입니다. 실행마다 20% 정도 흔들리는 환경이라 수치를
인용하지 않습니다. 인용하는 값은 [`2026-10-05_server`](../2026-10-05_server/2026-10-05_server.md)이고 해석은
[실험 17](../../../documents/reports/17_cpp_numpy_qiskit_baselines.md)에 있습니다.

| 위치 | 내용 |
|---|---|
| `environment.txt` | VM 사양과 Python package version |
| `verification/` | server benchmark와 같은 verification 다섯 종 (전부 PASS) |
| `predicate500/` · `common500/` | report와 교차 verification 결과 |
