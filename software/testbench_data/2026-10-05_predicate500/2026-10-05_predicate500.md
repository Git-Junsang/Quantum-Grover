# 2026-10-05 Predicate500 dataset

네 predicate(LT · GT · EQ · RANGE) × number of solutions 5종의 20 datasets(`dataset_<predicate>_target_<number_of_solutions>.bin`)입니다. reference model의 생성 규칙
(`reference_model_develop/models/common/benchmark_dataset.py`)으로 2026-10-05에 만들었고, hash가
[`reference_model_data/2026-09-25_predicate500/predicate500_datasets.csv`](../../reference_model_data/2026-09-25_predicate500/predicate500_datasets.csv)
와 같습니다. 다시 만드는 도구는 `pc_grover_develop/tools/make_predicate500_datasets.py`이고, PC용 Grover benchmark
(`pc_grover_develop/campaign/run_all.sh`)가 이 directory를 읽습니다. RTL testbench는 같은 규칙으로 자극을 따로 만들어 씁니다.
