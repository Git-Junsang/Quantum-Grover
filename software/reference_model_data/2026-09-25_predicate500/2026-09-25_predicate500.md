# 2026-09-25 Predicate500 expected result

네 predicate(LT · GT · EQ · RANGE) × number of solutions 5종 × seed 100쌍 = 2,000 workloads를 Q1.22 bit-exact reference model로
돌린 expected result입니다. RTL testbench(`make -C hardware_bram/sim predicate500`), SoC simulation, board 자동 test
(`software/host_fpga_develop/bbht_predicate500.py`)가 이 directory의 두 file을 판정 기준으로 읽습니다.

| file | 내용 |
|---|---|
| `predicate500_expected.csv` | workload 2,000 rows. 결과 index · shot count · requested iterations · mode별 executed iterations |
| `predicate500_datasets.csv` | 20 datasets의 threshold와 FNV-1a hash |

생성기는 [`reference_model_develop/predicate500/run_predicate500_golden.py`](../../reference_model_develop/predicate500/run_predicate500_golden.py)
이고, 기본 출력 위치가 이 directory입니다. 열의 뜻과 DRAM session 열이 따로 있는 이유는
[기술문서 4장 4.4절](../../../documents/design_references/04_software_reference_model_and_test_vectors.md#44-predicate500-expected-result)에 있습니다.
