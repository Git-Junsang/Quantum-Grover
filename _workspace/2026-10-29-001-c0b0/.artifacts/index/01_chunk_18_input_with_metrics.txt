# 윤문 진단

대상: `index.md`

## 장르와 레지스터

학부생용 공부 해설서입니다. 설명 본문은 합쇼체 중심의 친근한 존댓말이고, 질문·권유에는 해요체가 섞입니다. 요약·표의 간결한 명사형은 의도된 형식입니다. 이 register와 독자 수준을 그대로 유지합니다.

## 겨냥 순서와 근거

1. **D-14 / D-5 — 학습 서술을 지배하는 비유**: 「뿌리」·「토대」·「물속에서 헤엄치는 장치」·「지수적 폭발」·「야심이 부족해서」·「네 기둥」·「15.4절이 이깁니다」가 연속됩니다. 기존 비유 박스는 유지하되 어색한 본문의 비유를 저장·복잡도·학습 순서·기준 문서로 구체화합니다.

2. **D-8 / D-2 — 단정적 안내와 과한 평가**: 「완전히 체득」·「강력히 권합니다」·「취향이 아닙니다」·「둘을 더 못 박아」·「틀리면 좋았어라고 외치세요」 같은 표현이 교재 안내를 과장합니다. 학부생에게 설명하는 친근한 존댓말을 유지하며 현실적인 안내로 다듬을 여지가 있습니다. 발화자 있는 실제 인용은 그대로 둡니다.

3. **A-18 / A-19 — 긴 관형구·이중 조사**: Grover project 소개와 emulation 이유를 묶은 문장·독자 가정 문단을 확인합니다. relative_clause_nesting=14, double_particle_count=1. interface·predicate·complexity·scope 조건을 보존하고 한국어 연결만 고칩니다.

4. **C-8 / I-3 — 대립 구조와 반복적인 간접 설명**: 「…아니라」·「…것입니다」·「…데 있습니다」가 project 이유와 범위를 설명할 때 반복됩니다. simulator와 classical scan의 구별은 핵심이므로 남기고, 주변 메타 설명을 직접 진술합니다.

## 정량 앵커와 해석

입력 정량 블록의 route_hint는 `heavy`, 원문은 20,847자입니다. 위에 적은 양성 카운트만 해당 ID의 보조 근거로 사용했습니다. lexical_diversity의 낮은 값은 전문용어 반복의 영향이 있으므로 영어 용어를 치환하는 근거로 쓰지 않습니다. 이중 피동·by 피동·have 직역은 카운트가 0이어서 지배 패턴으로 지목하지 않습니다.

## 보존 지침

- 영어 용어·영어 토큰의 철자와 대소문자를 그대로 둡니다. 영어를 한국어로 옮기거나 동의어로 바꾸지 않습니다. 용어집 SSOT는 `documents/design_references/22_appendix_glossary_and_retired_specs.md` 22.2절입니다.
- 사실·주장·수치·단위·수식·code·identifier·인용·조건·부정/긍정·인과를 보존합니다. 내용 보충이나 과학적 사실 수정은 이번 윤문의 범위가 아닙니다.
- 제목·절 번호·link·그림·기존 콜아웃·표 구조를 유지합니다. 기존 볼드·이모지는 교재 고유 관습이므로 일괄 삭제하지 않습니다.
- 어색한 비유·한국어 연결·조사·수식어만 국소 수정합니다. 단순히 technical term이 많이 나온다는 이유로 B 계열 처방을 적용하지 않습니다.
- 의무·가능·추정의 강도를 보존하고 원문에 없던 설명이나 평가를 넣지 않습니다.

### 읽는 순서

각 장은 바로 앞 장의 개념 위에 세워집니다. 순서대로 읽는 것을 강력히 권합니다. 특히 **superposition(1장) → gate(3장) → measurement(4장) → phase kickback(7장)** 은 Grover를 이해하는 4개의 기둥입니다. 0~10장이 quantum 이론이고, 11장부터는 그 이론을 실제 circuit으로 옮기는 이야기라 FPGA 기초(LUT·FF·BRAM·DSP)를 함께 가정합니다. 이론만 필요하다면 10장에서 멈춰도 됩니다.

```
처음 배우는 사람:               1장 → 2장 → ... → 9장  (순서대로)
linear algebra에 익숙한 사람:   1~2장 빠르게, 3장부터 정독
Grover만 급히 볼 사람:          1·3·4·5·6.2·7장 훑고 → 9장 (모르는 개념은 앞 장 참조)
hardware까지 갈 사람:           9장까지 마치고 → 11 → 12 → 13 → 14 → 16 → 17 → 18
                                (FPGA 배경이 있으면 11.5·11.6절은 훑고 넘어가도 됩니다)
```

**12장을 13장 앞에 두는 것은 취향이 아닙니다.** 13장은 amplitude 한 칸이 Q1.22 fixed-point라는 것, round-half-to-even이 어느 지점에서 일어난다는 것, 넘치면 saturation이 걸린다는 것을 전부 12장의 결정으로 **전제하고** 씁니다. 12장을 건너뛰면 13장의 shift 위치와 data word 폭이 근거 없는 숫자로 보입니다.

15장은 순서에 넣지 않았습니다. 참조용이라 11~14장을 읽은 뒤 아무 때나 펼치면 되고, 확정된 수치가 필요할 때마다 [15.4절](15_paper_map_and_design_decisions.md#154-우리-project의-좌표--확정-설계-결정표)로 돌아오게 됩니다. 다만 논문을 **인용하기 전에는** 반드시 [15.6절 정오표](15_paper_map_and_design_decisions.md#156-인용-시-주의--논문의-오류와-모호점)를 먼저 보세요.

각 장은 시작 부분에 **"이 장을 읽기 위한 준비"** 로 필요한 배경 지식을 링크합니다. 개념은 앞 장에서 뒤 장으로 단조롭게 쌓이도록 배치했습니다.
