## 장르와 레지스터

학부생용 공부 해설서입니다. 설명 본문은 합쇼체 중심의 친근한 존댓말이고, 질문·권유에는 해요체가 섞입니다. 요약·표의 간결한 명사형은 의도된 형식입니다. 이 register와 독자 수준을 그대로 유지합니다.

## 겨냥 순서와 근거

1. **D-14 / D-5 — 동작을 과장한 의인화·비유**: 「circuit으로 내렸습니다」·「설계를 통째로 뒤엎습니다」·「손끝 하나 달라지지」·「function을 먹였으니」·「귀납이 끝났습니다」·「measurement를 무너뜨립니다」·「checkpoint가 살아」 등은 동작·증명·유효성 설명으로 바로 쓸 수 있습니다. 기존 제목의 표현과 technical term은 보존합니다.

2. **D-8 / D-2 — 예고와 감탄의 누적**: 「여기가 이 장의 본론」·「마지막으로 눈여겨볼 것」·「좋은 소식」 같은 문패가 실제 설명 앞에 붙습니다. 수식·조건·실패 규약을 손대지 않고 불필요한 안내만 줄입니다.

3. **A-18 / I-3 — 긴 조건부 설명과 형식명사**: 14.3·14.4·14.7·14.8은 긴 괄호·대시와 「…것입니다」·「…뜻」이 거듭됩니다. relative_clause_nesting=9. sampling의 균등 조건과 checkpoint 무효화·종료 조건이 흐려지지 않게 문장을 나눕니다.

4. **C-8 — 「공짜/공짜 아님」 대구 반복**: 14.1 도입·이후 설명·요약에서 대립이 누적됩니다. oracle·diffusion operator의 cycle 불변성과 measurement·iteration-control의 추가 고려라는 실질 구별을 유지하고 본문의 반복 비유만 완화합니다.

## 14.0 기호 충돌 주의

이 장이 인용하는 세 자료가 **같은 글자를 다른 뜻으로** 씁니다. 이걸 정리하지 않으면 수식을 따라가다 반드시 헷갈립니다. 그래서 이 해설서는 **글자 대신 용어를 그대로 쓰고**(아래 표의 둘째 열), 원문을 인용할 때만 환산하겠습니다.

| 개념 | **본 해설서(통일)** | 08번 논문 | 09번 논문 |
|---|:---:|:---:|:---:|
| search space의 크기 | number of states | $D$ | $K = 2^N$ |
| solution의 개수 | number of solutions | $M$ | $S$ (또는 $n_s$) |
| (08의 $N$) | — | diffusion operator가 뒤집는 state의 개수 | — |
| (09의 $N$) | — | — | 사용자 수 |

특히 조심할 것 두 가지입니다. **08번의 $N$ 은 number of qubits도 search space도 아닙니다** — diffusion operator가 phase를 뒤집는 state의 개수라는, 그 논문만의 variable입니다. 08번에서 search space는 $D$ 입니다. 그리고 **09번의 $N$ 은 "사용자 수"이고 search space는 $K=2^N$** 입니다. 그래서 09번의 optimal number of iterations 공식에 $S=1$ 을 넣으면 우리에게 익숙한 $\frac{\pi}{4}\sqrt K = \frac{\pi}{4}\sqrt{2^N}$ 이 나오지, $\frac{\pi}{4}\sqrt N$ 이 아닙니다. 교과서의 "$\frac{\pi}{4}\sqrt N$"은 $N$ 을 search space의 크기(이 해설서의 number of states)로 쓴 표기이니, 09번을 읽을 때는 반드시 $N\to K$ 로 환산하세요.

이 표를 손 닿는 곳에 두고, 아래부터는 search space의 크기를 number of states, solution의 개수를 number of solutions로 읽으시면 됩니다.
